Using the visualization

Start with the seed, then compare the band at global and local scales. Rotate the saved geometry and follow the completion one piece at a time.

  1. Seeds and the ruled band; switch between the seed, band and normal image.
  2. Band width and local views; read each model's units before comparing scales.
  3. Alternative bands and their return flow; use the circuit slider and mesh toggle.
  4. Positive exits, connectors, duality, filling, the inner end and the neck.
  5. Reflected saddle annulus, convex closure and normals, affine marking and opposite bending signs.
  6. The six ver503 figures, including bending/asymptotic leaves and the Cantor-family sketch.

Controls

Drag to rotate, scroll to zoom and shift-drag to pan. Use the model buttons, Reset view, Full screen, and Save picture. Show belt mesh reveals sampled rulings. The circuit slider on return pages reveals saved trajectories. Left/right arrow keys move between construction chapters.

How to read the models

These are cached finite-resolution numerical illustrations. The twelve-cell example is below the paper's sufficient analytic range. Completion meshes preserve their computed pieces but do not implement all internal relative smoothing. The local microscopes use uniform magnification; read each caption's units. Broad alternative bands may self-intersect. Numerical tests and smoothness claims are distinct; the latest Lean formalization remains incomplete.

Running locally

Serve the repository root using Python's static HTTP server: python -m http.server 8000 --bind 127.0.0.1. Then open http://127.0.0.1:8000/visualization/index.html. Keep the adjacent paper and lean directories so their links work. No browser solver, account, external asset service or JavaScript package installation is required.
