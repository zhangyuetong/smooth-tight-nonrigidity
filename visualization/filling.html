What this step does

All the wavy boundary data stay in the angular cutoff term. Farther inward that term disappears, leaving a rotationally symmetric quadratic germ. This is how the actual complicated attachment reaches an explicit radial end.

The large coefficient is visible in the true graph: it produces a large height and a rapidly expanding gradient image. The local seam view resolves the original incoming data; the full filling shows the resulting proportions.
